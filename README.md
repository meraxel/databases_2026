\### Документирование нарушений ограничений целостности



| № | Ограничение | Выполняемый запрос (SQL) | Сообщение СУБД | Понятное сообщение для пользователя | Как исправить |

|---|---|---|---|---|---|

| 1 | \*\*CHECK\*\* | `INSERT INTO employee (full\_name, email) VALUES ('Иван', 'ivan\_mail.ru');` | `new row for relation "employee" violates check constraint "employee\_email\_check"` | «Неверный формат электронной почты. Email должен содержать "@" и домен.» | Ввести email в правильном формате, например: `ivan@mail.ru` |

| 2 | \*\*FOREIGN KEY\*\* | `INSERT INTO task (project\_id, status\_id, title, created\_by) VALUES (9999, 1, 'Задача', 1);` | `insert or update on table "task" violates foreign key constraint "task\_project\_id\_fkey"` | «Указан несуществующий проект. Задача не может быть создана без проекта.» | Выбрать `project\_id`, который существует в таблице `project` |

| 3 | \*\*UNIQUE\*\* | `INSERT INTO project (name) VALUES ('Альфа-Проект');` \*(повторно)\* | `duplicate key value violates unique constraint "project\_name\_key"` | «Проект с таким названием уже существует. Пожалуйста, выберите другое имя.» | Указать уникальное название в поле `name` |

| 4 | \*\*NOT NULL\*\* | `INSERT INTO status (status\_name) VALUES (NULL);` | `null value in column "status\_name" of relation "status" violates not-null constraint` | «Название статуса обязательно для заполнения и не может быть пустым.» | Передать текстовое значение в поле `status\_name` |

| 5 | \*\*PRIMARY KEY\*\* | `INSERT INTO status (status\_id, status\_name) VALUES (1, 'Custom');` \*(если ID 1 занят)\* | `duplicate key value violates unique constraint "status\_pkey"` | «Статус с таким системным идентификатором уже зарегистрирован.» | Не передавать `status\_id` вручную, позволив БД сгенерировать его |
